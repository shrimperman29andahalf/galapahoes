# Galápagos '26–'27 Trip Site

A mobile-first friends-trip planning hub for Dec 27–Jan 5.

## Files
- `index.html` — page structure/content
- `style.css` — design and responsive layout
- `script.js` — temporary demo interactions

## GitHub Pages
1. Create a public GitHub repository.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the Pages URL.
